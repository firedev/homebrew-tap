# firedev/tap

Homebrew tap for [firedev](https://github.com/firedev) tools.

```sh
brew install firedev/tap/threefinger
brew services start threefinger

brew install firedev/tap/matrix
```

| Formula | Description |
|---------|-------------|
| [threefinger](https://github.com/firedev/threefinger) | Swipe with three fingers on the Mac trackpad to change tabs |
| [matrix](https://github.com/firedev/matrix) | Matrix rain screensaver for the terminal — any key launches your command |
